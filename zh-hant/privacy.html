Zepunari：幼兒旅行遊戲隱私支援

隱私權政策

最後更新： 2026-10-16

Zepunari 刻意保持簡單：不需要帳號、沒有廣告、沒有第三方追蹤，也不會在遊戲過程中自動收集個人資料。

  • 遊戲過程中不會自動收集、上傳或分享兒童或家長的個人資料。
  • 不需要建立帳號，也不會要求姓名、生日、Email、電話或其他聯絡資料。
  • 不會要求相機、麥克風、照片、通訊錄或精確位置權限。
  • 目前版本沒有第三方分析、廣告或追蹤 SDK，也不使用 IDFA。
  • 核心玩法、設定與內建音樂都在裝置本地運作；目前沒有 App 內購買或訂閱。

家長主動寄送的支援郵件

家長自願寄信聯絡支援時，電子郵件服務會處理寄件位址和信件內容，以便投遞及回覆。請勿提供兒童姓名、照片、位置、學校或其他不必要的個人資料。這與離線核心遊戲的資料處理不同。

網站託管與 IP 位址紀錄

本隱私權政策與支援網頁由 GitHub Pages 託管。根據 GitHub 官方文件，造訪 GitHub Pages 網站時，無論訪客是否已登入 GitHub，GitHub 都會基於安全目的記錄並儲存訪客的 IP 位址。此網站存取行為與 Zepunari 的離線核心遊戲過程不同。 GitHub Pages 官方文件 · GitHub 隱私權聲明.
