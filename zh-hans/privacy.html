Zepunari：幼儿旅行游戏隐私支持

隐私政策

最后更新： 2026-10-16

Zepunari 刻意保持简单：无需账号、没有广告、没有第三方追踪，也不会在游戏过程中自动收集个人数据。

  • 游戏过程中不会自动收集、上传或分享儿童或家长的个人信息。
  • 无需建立账号，也不会要求姓名、生日、Email、电话或其他联系资料。
  • 不会请求相机、麦克风、照片、通讯录或精确位置权限。
  • 当前版本没有第三方分析、广告或追踪 SDK，也不使用 IDFA。
  • 核心玩法、设置和内置音乐都在设备本地运行；当前没有内购或订阅。

家长主动发送的支持邮件

家长自愿向客服发送邮件时，邮件服务会处理寄件地址及邮件内容，以完成投递和回复。请不要发送儿童姓名、照片、位置、学校或其他不必要的个人信息。这与游戏离线运行的数据处理不同。

网站托管与 IP 地址记录

本隐私政策及支持网页由 GitHub Pages 托管。根据 GitHub 官方文档，访问 GitHub Pages 网站时，无论访问者是否登录 GitHub，GitHub 都会出于安全目的记录并存储访问者的 IP 地址。访问这些网页与 Zepunari 的离线核心游戏过程是两回事。 GitHub Pages 官方文档 · GitHub 隐私声明.
